VIAGGIO IN PUGLIA — progetto QR per i tavoli del matrimonio

CONTENUTO
- index.html: pagina principale con le 15 città
- una pagina HTML per ogni città
- qr-code.html: pagina con tutti i QR code pronti da stampare
- 15 immagini PNG dei QR code
- style.css: tema grafico elegante Puglia Wedding

NOTE
I QR code usano gli URL pubblici di GitHub Pages e sono generati con una zona bianca centrale per mantenere la leggibilità.
Le immagini di sfondo vengono gestite dal workflow automatico; quando viene usata un'immagine esterna, il credito viene registrato in IMAGE-CREDITS.txt.
